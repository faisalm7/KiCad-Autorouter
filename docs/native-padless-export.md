# Temporary padless export identities

The current source promotes the mechanism qualified by the [Roller generated-route diagnostic](../evidence/roller-generated-routing-native001-001.json). Fresh normal-workflow qualification is still pending. The installed installation030 predates this change.

Duplicate footprint references are allowed only when every member of that group is padless, board-only artwork with a unique UUID and a noncopper Reference field. Aliased artwork cannot have models, and variable-dependent surface text is outside this scope. The qualified geometry observer is limited to modern two-layer boards with F.Cu signal and B.Cu signal or jumper. Electrical duplicates remain unsupported.

The exporter captures the exact routing task and original project hash. It changes the artwork references only in the loaded board during DSN export, checks the full native geometry during that interval, and restores the references before writing any board. Original source and project files remain unchanged. Raw DSN, the complete reference mapping, four observations and original-reference native emissions are retained in the run folder. An explicit zero-alias proof is mandatory for ordinary exports too; a failed plan never falls back to an unchecked export.

Import omits the optional SES placement section through the existing fixed-placement helper. Temporary aliases must be absent from every imported routing token. The final candidate must independently preserve the original design and protected copper, survive saved zone refill with unchanged route-net identities, and pass original-rule native validation including the complete schematic when present. Export geometry equality is not a clearance or routing pass.

The full original project remains authoritative for class resolution. One unused, fully specified second class may remain alongside Default when there are no class patterns or assignments and every native net resolves to Default. The original unused class and all dimensions remain in the project. Active numeric-leading class mappings remain unsupported. Root F.Cu/B.Cu knockout text is preserved; text on Edge.Cuts and ambiguous selectors remain blocked.

This applies to normal native-guidance export. The separate floor/placement exporter keeps its existing duplicate-reference restrictions. It has not inherited alias qualification. No source reference is renamed permanently and no design rule, severity, exclusion, copper layer type or graphic is removed.

Comparative experiments must distinguish the raw-DSN standard-engine control from an unmodified stock export workflow. The common safety wrapper includes fixed-placement import and these temporary identities, and all corrected/tuned/proposed arms use the same wrapper. A routing improvement must beat the corrected and tuned arms under equal measured budgets; exporting this board successfully does not establish that improvement.
