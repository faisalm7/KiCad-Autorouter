Preview displays static support information. Route starts the worker; progress and Cancel remain available. Partial completion protects all existing copper, while whole-board routing preserves locked copper. Unknown or unsupported requirements refuse; names and DRC cannot establish current, return-path, impedance or timing fitness.

Create review provides front/back and relevant-layer before/after images plus complete findings, warnings and ignored checks. Use **Microsoft Edge**. An opened review project is a disposable inspection copy; close its editors and project before acknowledging review. Explicit Reject disables export; Accept records software intent, without engineering approval or live application.

Fresh export performs new original-rule Native validation into another separate project. Open checked export checks current proof before opening it.
