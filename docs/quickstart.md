# Saved-project workflow

Start from your installed launcher and your own complete saved KiCad project. [Start here](../START_HERE.md) covers launching and source selection; [advanced installation and CLI](install-existing.md) covers terminal setup. The workflow does not require an AI account, model endpoint, research archive or prepared GUI session.

The [102live application task](../evidence/copilot102-owned-live-delivery-001.json) completes one owned placement/routing delivery with0opens/0blocks/1unchangedwarning and2ignored checks. [101graphical safety](../evidence/product101-GUI124-core-001.json) supplies unchanged-core negatives/checked opening; [094](../evidence/runtime094-GUI118-core-001.json) remains the older licensed reference. Use the [portable owned walkthrough](../examples/owned-placement-routing/README.md) or your own supported complete project, with fresh inspection. These same-Mac/exposed results are not independent installation or broad usefulness.

**Optional copilot:** after choosing parts, region, copper permission and budget, open **Assistant · optional**. Read the exact data/cost summary before sending a consented request. The model proposes a visible plan only; use it explicitly to find local alternatives, then follow the same move/Native/routing/review approvals below. Core tools work without it. Sol/medium is provisional; a loopback server is not proof of offline inference and no subscription supplies application API access. Never paste credentials into chat or change engineering requirements to fit a response.

1. **Capture the saved source.** Keep the PCB, project, complete schematic and original rule files together. Save and close source editors and choose **File → Close Project** in KiCad manager, then choose the exact PCB and a separate output folder, and inspect the source. Unrouted connections can be valid routing demand; blocking findings or unsupported geometry must be addressed without weakening rules. Unsaved editor buffers are not an authoritative input.
2. **Choose routing or placement.** For direct routing, choose scope, protected content, layers and budget in ordinary controls. **Finish gaps** preserves existing routing; rerouting unlocked copper must be explicit. For placement, select eligible movable parts and an allowed rectangle. All unselected/fixed parts stay fixed. Orientation and side remain unchanged. Keep existing copper protected, or explicitly permit the supported affected-net rebuild policy and review exactly what it will rebuild and retain.
3. **Compare placement drafts when requested.** Use **Find placement alternatives** and inspect the diagram, numeric coordinates and copper plan. Allowed coordinate edits still use shared constraints; an invalid edit retains the previous pose. The target-region checkbox is a specific opt-in for two independent selected parts in the supported Native source-baseline scope. It does not repair source collisions or authorize other geometry changes. The search may return no changed alternative. Review and acknowledge the exact draft; if on Findings, return to **Board** before choosing **Validate placement**; a validated placement opens routing settings with its origin/protection guard attached.
4. **Preview and route.** Preview is a static support check, not Native acceptance. Start Route only after reviewing the visible settings. Keep the saved source closed and unchanged. **Cancel** requests owned-worker cleanup and revokes results; wait for it to finish. A source, settings, pose or policy change requires a fresh preview or placement review.
5. **Review the result.** Create the separate review copy, inspect both copper layers and all findings in your configured browser, and choose **Accept intent** or **Reject intent**. Qualification used Microsoft Edge. Accept records intent only; it does not waive warnings, grant human PCB approval or apply a candidate to a live editor. Reject keeps the original and evidence without accepting an export.
6. **Make a fresh separate export.** Fresh export reruns original-rule Native validation, including refill/connectivity and schematic/design/protected-copper checks. Open only through **Open checked export** while the retained proof is current. Normal KiCad opening or subsequent editing can change the project/file set and make that proof stale. Save further edits as a separate complete working project and choose it as a new source task; never renew proof by editing receipts or restoring sidecars.

Native routing acceptance is scoped to the requested routing task and bound candidate. It is not the same as a completely DRC-clean project, and neither establishes electrical or manufacturing suitability. Review every warning and ignored check; preserve the original rules and protected content.

The101GUI124control observes active owned Native source-DRC cancellation and cleanup; other phases remain unqualified. Older missed/limited controls stay recorded. Genuine changed-warning interaction, exact queued-opening timing and every Native cancellation phase remain unexercised. No complete GUI CPU/interaction performance or human cleanup benefit is measured. Live apply/undo, standalone/independent installation and Windows Native support remain open.
