# Ordinary Route class-parity qualification

This bounded integration closes a documented fidelity blocker. The retained
runtime006 counterexample accepted a schematic CRITICAL directive while its
PCB selected POWER. The qualified pure comparator now participates before the
engine, after final Native validation and in fresh separate-project export.

Only the explicit ordinary Native Route context may request this check: whole
unlocked routing or partial completion, source layers and known flat class
identities. Improve, Recover, placement, selected-net class transport,
hierarchy and unknown class inheritance remain blocked. A preview is pending
Native verification, never class or routing acceptance.

`fixture.files()` derives a matching POWER directive from the existing owned
four-copper open-ROUTE task, preserving ten locked KEEP segments, the original
four layers, constraints and pours. `clean_fields=True` authors an owned variant
whose PCB Datasheet placeholders equal its schematic; this tests that class
proof does not depend on field warnings. `mismatch=True` retains the exact
CRITICAL directive. These are exposed controls in one family, not added
independent coverage or evidence of routing superiority.

Qualification must use a new curated runtime and the existing
`scripts/qualify_runtime_workflow.py` controller, then central current readers.
Both positive variants need actual engine/import/refill/fullSCH/class proof
and fresh export. The mismatched case must refuse specifically before engine
work. Missing/downgraded/stale proofs and source changes must refuse; cancellation
must preserve failure artifacts without accepted fallback. Store actual failures
and resource costs. Source is an unqualified integration draft until these run.
