# Four-copper class transport control

This project-owned GPL-3.0-or-later factory creates a separate, complete flat-schematic project with four canonical signal layers and three Native-resolved classes. The original two-copper factory is unchanged. `COPYING` covers this factory and its generated design.

ROUTE has front/back SMD endpoints; KEEP has an authored locked trace. GND is another disconnected pair. No zone or custom-rule file is created. This is a synthetic interchange control, not a board family, electrical design recommendation or routing-quality comparison.

The implementation requires exact source/Native/DSN layer identities, all four through-via copper shapes, original class dimensions and parameter parents, complete pad counts and retained source/export cross-binding. Missing metadata, partial spans, aliases and unsupported geometry refuse. The two-copper receipt branch remains separate.

Native qualification is pending. A front/back route alone does not demonstrate use of an inner-layer track. Actual inner-layer transport, both pinned KiCad versions, same-original-rule invalid controls, shared final validation and original/protected-source checks are required before any broader support claim. HFE's parity, pour and numberless-pad restrictions remain unresolved.
