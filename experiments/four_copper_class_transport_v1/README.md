# Four-copper class transport control

This project-owned GPL-3.0-or-later factory creates a separate, complete flat-schematic project with four canonical signal layers and three Native-resolved classes. The original two-copper factory is unchanged. `COPYING` covers this factory and its generated design.

ROUTE has front/back SMD endpoints; KEEP has an authored locked trace. GND is another disconnected pair. No zone or custom-rule file is created. This is a synthetic interchange control, not a board family, electrical design recommendation or routing-quality comparison.

The implementation requires exact source/Native/DSN layer identities, all four through-via copper shapes, original class dimensions and parameter parents, complete pad counts and retained source/export cross-binding. Missing metadata, partial spans, aliases and unsupported geometry refuse. The two-copper receipt branch remains separate.

[Actual Native qualification](../../evidence/four-cu-class-native-001.json) now passes on both pinned versions using forced_inner.py: new inner ROUTE/GND tracks, full-through vias, ten original protected tracks, full schematic/effective fields and same-rule shorting negatives. Both final outputs retain six qualified field warnings. The simpler front/back fixture alone still does not prove inner-track use. These exposed controls establish no independent board family, electrical approval or comparative gain. Broader aliases/formats/pour/selected/layer-mask scopes and current installation remain separate gates. HFE remains rejected.

The factory declares net-settings schema5 and an explicit empty tuning profile for each class. Actual Native1000 controls caught missing-field class fallback; metadata alone failed, while the complete authored schema passed. Native1007 has its own positive census. These are observer controls, not route qualification. `forced_inner.py` adds ten locked KEEP tracks forming outer copper curtains; an eventual accepted route must contain real new inner segments on ROUTE and GND plus full-through vias. Actual original Native has two opens and no blocking findings; final accepted candidates and deliberately invalid controls are retained in the linked evidence.
