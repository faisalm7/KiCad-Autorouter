# Required original-source audit after a completed acquisition

No action here downloads dependencies, executes datasets, renders code or calls native tools. Start only after ROOT announces immutable acquisition completion. Keep original bytes unchanged and bind the completed receipt, committed helper, protocol and full before/after inventories. Record any partial acquisition as such; do not remove a failed board from coverage.

1. Verify all14 original files' exact Git blob/size/SHA256 against response records and the pinned tree. Verify all345 previous files remain exact. Confirm actual native PCB/project/schematic count, source versions and any nested sheet/rules references. Match the project stem; preserve original PRL, filename metadata and every source constraint.
2. Read original README/LICENSE and inspect native/local footprint headers and per-file exceptions. Record the CERN-OHL-P-2.0 publisher grant with original notices. Inspect photo/graphic attribution separately before any public payload curation. Do not treat root licensing or missing notices as proof of third-party author permission. Acquisition approval is not bulk publication approval.
3. Parse board/project/schematic read-only: copper layers/stackup, nets/terminals, footprint positions and pad primitives, arcs/cutouts, netclasses/patterns, local clearance, zones/teardrops, prohibited areas, protected routing, custom rules, DRC severities/exclusions and tuning/high-speed intent. Use existing preflight only for diagnosis; preserve unsupported fields rather than widening gates. README's declared two layers/3.3V remains distinct from observed source and electrical validation.
4. Resolve original `fp-lib-table` entry `${KIPRJMOD}/paw3395_pcb.pretty` against the acquired PAW3395 footprint. Read every model URI in that file and embedded board footprints, plus every schematic symbol/library identifier. Build exact original URI → existing source path/revision/notice or explicit unresolved mapping. Include local/generated and stock references separately. A local footprint/table is evidence of local availability, not automatic copyright ancestry or model closure.
5. If `${KICAD*}`, user variables, absolute paths, global stock aliases, nested sheets or model references lack an authentic version/path, stop that closure branch as incomplete. Do not invent alias tables, substitute current libraries, infer model authorship, remove references, or fetch broad libraries. Any necessary new source request needs a bounded, metadata-grounded proposal. Embedded symbol/pad geometry does not establish all external dependency identities.
6. Trace repository history and referenced sensor/driver designs enough to group PAW3395/PAW3950 variants and compare circuit/terminal partitions with the19-board population. Shared passive templates or different repository names are insufficient for independence. Do not inspect reserved holdouts. Reference routing is exposed development data, never a solver seed.
7. Publish a compact per-board disposition with exact bytes, rights scope, authentic dependencies, format/constraint blockers and ancestry uncertainties; retain raw originals privately in `.data`. Successful fetch alone only increases the acquired denominator19→20. Native support, full DRC cleanliness, human review, physical/electrical adequacy and B0/B1/B2/C improvement remain separate future gates using existing workers/validation.
