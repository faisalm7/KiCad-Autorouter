existing original-project, layer/text controls and protected alias transport
are retained and re-read; they must not be executed again.

aliases affect only padless reference identities during export. All SES

Actual saved refill, whole-original DRC, complete schematic parity, original
warning identities, Native class mapping, route dimensions and final metrics
must pass. Only after that positive may one physical different-net pad bridge
be checked, requiring a fresh UUID-bound Native error. No project file with the
unused class removed is ever saved or passed to Native KiCad.

The prospectively frozen protocol pins source, helper code and prior evidence.
The run has a 120-second wall and full-CPU cap, one engine, a 4 GiB sampled
process-group guard and 64 MiB output ceiling. The outer timeout is 115 seconds;
two seconds cover bootstrap/publication and three are reserved for independent
read-back. Guards are polling limits, not an OS memory sandbox. Native commands
use the existing network-denying sandbox. Source tests and earlier development
attempts are disclosed separately; this is no equal-budget quality comparison.

After review, a verified source checkpoint and incremental raw backup, run once:

```sh

```

receipt. A failed positive stays failed; its final Native evidence is retained.
Missing-only continuation requires a new reviewed protocol and carries prior
costs. This does not qualify a normal workflow, algorithmic improvement, an
independent board family, asset redistribution, human PCB or electrical review.
