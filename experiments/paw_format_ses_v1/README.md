# PAW old-format transport qualification

This frozen development diagnostic reuses the original-project and KiCad8
compatibility helpers. It neither changes the source version nor admits it to
normal routing. All aggregate acceptance and production flags stay false.

After the source checkpoint, run through the bounded local controller recorded
in `PLANS.md`. The actor additionally requires `--run-native`. No acquisition or
previous DRC controls are repeated: three missing current-native emissions and
two saved/shell reload contexts reuse the retained original observation. Exact
non-fill AST, UUID route records, terminal/net/class and rule comparisons must
pass before a newly unrouted task reaches one tuned Freerouting invocation.
Its real SES import/transplant receives fresh original-rule, full-schematic,
PRL and independent legacy-zone checks. A deliberately changed imported MISO
net must fail fresh Native validation.

The new diagnostic has a 120-second wall/full-CPU cap including a 3-second
bootstrap allowance; its outer controller checks whole delivery. Retained
output is bounded at 64 MiB, each worker directory at 20 MiB, worker group RSS
at 4 GiB, and logs at 256 KiB. Polling limits can overshoot. One worker runs at
a time. Prior qualification costs are retained separately, and this diagnostic
is not a fair routing-method comparison or a claim of general format support.

`input-pins.json` freezes the current source and complete retained prefixes.
Unexecuted agent drafts, the initial import failure and the corrected no-opt-in
control are preserved in `.runs`; this is project-owned orchestration, with no
raw third-party project or downloaded engine redistribution.
