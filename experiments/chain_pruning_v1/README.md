# Endpoint chain deletion experiment

This is an opt-in `strategy.prune(..., proposal_policy="chains")` experiment. The normal CLI and default single/feedback policies are unchanged. It tries whole-zone deletion, one batch of endpoint groups, then existing individual deletions and bounded warning cleanup. Every proposal uses the same eligibility/protected-route filter, Native saved refill, original-shell reconstruction, original-rule DRC and final quality/publication checks. Global budgets and trial/final reserves are unchanged.

A group is a deletion hypothesis. Exact endpoint adjacency does not establish electrical connectivity, and contacts away from endpoints are not inferred. All incumbent routes enter the degree census. Branches, vias, arcs, protected items, different nets/layers/widths and conservative footprint-centred pad envelopes stop continuation. The envelope contains ordinary pad positions under rotation/flipping, at the cost of missed groups. Trapezoid/custom/unknown pad envelopes decline this proposal type visibly. No reference copper chooses proposals and no DSN/terminal demand is rewritten. Native component observations are deliberately absent from this first grouping ablation.

Bounds are4,096routes/1,024pads/256groups/32segments per group. Native coordinates must be integral nanometres; no rounding or nonfinite/exponent/oversize literals. Closed cycles and duplicate geometric segment edges are refused/skipped. Every batch binds the exact incumbent bytes used to construct it. Oversize groups and declined reasons remain in the result. Groups are generated once after whole-zone trials; accepted changes can make a retained group unavailable, in which case it is skipped. This is a bounded heuristic, not an exhaustive optimizer.

Actual source tests exposed duplicate-edge grouping, decimal precision/overflow, trapezoid-envelope and batch-hash freshness defects before Native execution. Their regressions and fixture/test setup failures are preserved. The constructed native control has an essential GND bridge between filled islands and a separate20-segment/16.5mm redundant chain; it is an owned GPL smoke derivative, never a benchmark or reference-route oracle. Whole deletion must retain its Native rejection, singleton deletion must retain new dangling warnings, and grouped deletion must pass actual complete original/protected/Native checks. Those Native outcomes are still prospective at this source checkpoint.
