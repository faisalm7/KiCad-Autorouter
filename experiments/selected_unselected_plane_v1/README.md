# Selected-net literal-plane prototype

This is a deterministic pure feasibility prototype outside the ordinary product
and its test discovery. It performs no file operations, Native export, routing,
acceptance or approval. It changes no `autorouter/` code and is not included in a
runtime. The original B1 suppression policy is unchanged.

`policy.capture(source_bytes, dsn_bytes, names)` uses the existing exact selected
binding, coherent source net identities, DSN parser/unit checks and selected DSN
class census. It describes ordered direct plane nodes. `policy.apply` freshly
derives and compares that context, omits planes on explicitly selected nets and
retains every unselected plane's exact AST and order. All other DSN nodes survive.
Names express identity only: selecting a net called `GND` omits its planes too.
The returned authority flags are always false.

This deliberately bounded prototype accepts the existing 20241229/20260206
two-copper syntax, F.Cu/B.Cu DSN layers, complete equal source/DSN net census and
single zero-width literal polygon shapes. A plane needs a matching named source
zone/layer witness. Raw inputs are limited to 2 MiB each, contexts to 256 KiB,
planes to 256 and vertices per polygon to 4096. Unsupported or malformed inputs
refuse; these bounds are not a new product support declaration. Source/zone/net
agreement does **not** establish that a supplied DSN came from Native KiCad.

The controls are authored syntax fixtures, not Native-qualified boards. Run only
the small explicit module with the existing bounded process helper:

```sh
.venv/bin/python -B -m unittest experiments.selected_unselected_plane_v1.controls
```

Integration would require the actual pinned Native export process/receipt, original
snapshot, Native mapping and Default-target lineage. Both existing
`check_native_edge_transport` and `check_pour_evidence` must independently derive
the same context, with a captured versioned capability and exact input/output
proof. Missing, deleted or modified context must not downgrade to historical
suppression. Existing graphics, selected-plane suppression, dimensions, original
zone intent, protected copper, Native refill/DRC, cancellation, freshness and
approval boundaries remain mandatory. These pure controls do not qualify default integration.

Literal outline transport does not reproduce actual Native fill islands, holes,
thermals or clearance topology. Retaining a large plane may make routing harder
and may still allow a later refill split. Runtime086's independent missing OUT
connection was already absent in SES; this helper does not solve it or establish
any routing benefit.

If the pure prototype and skeptical review justify integration, permit only one
prospectively frozen comparison: fresh existing baseline and fresh variant on the
exact retained Q86 pose/project bytes and explicit selection, run sequentially.
Each arm keeps the original 90-second wall/full-CPU routing budget and existing
reserves/settings; all preparation, conversions, checks and reporting share an
explicit 420-second total wall/full-CPU envelope. Do not repeat placement search,
change the pose, tune OUT, restart, fall back, alter constraints or count an old
failure as a fresh baseline. Preserve all failures, costs and warnings. Any final
open remains incomplete. Stop after one arm each; invalid/regressing/unhelpful
results defer or limit this policy. A useful result would still need unrelated
qualification before any default decision. Core087, full259 and current GUI
closure remain independent priorities.
