# Prospective whole-DSN area/contact capability probe

**Uncompiled and unexecuted.** ROOT alone may compile/import after independent review, exact source promotion and a verified checkpoint. There is no router, native CAD, SES writer, candidate acceptance or production support change in this helper.

The six fixed inputs derive from the already native-observed owned front0/back90 scenes in `evidence/pic-custom-native-controls-002`. Each full raw DSN is retained in the copied source evidence. Exactly two custom padstack hull shapes are replaced with their original 0.3 mm rectangular anchors; exactly two protected, same-net wiring polygons are appended from the native saved effective-world contours. A reverse AST proof requires every other DSN node—including pin/package names, placements, networks, widths, clearances, via rules and traces—to remain unchanged. Source boards, projects and native reports stay byte-identical. The original DSN has a 62.5 µm smd_smd exception; this helper does not edit it.

The pinned whole-board importer is `DsnReader.readBoard`. Actual JAR declarations and bytecode in `api-bindings.json` establish that null observer/ID arguments acquire internal defaults and that successful board/warning accessors exist. The probe requires `RoutingBoard`, waits for post-load work, then observes the imported state, explicit `changePlaneAsObstacle(false)`, and explicit `true`. That verified API updates area flags/rules and reinserts the tree. No autoroute call is made.

Each state retains actual bounded counts, complete original pin identities and centers, exact native-derived area contours and anchor dimensions, all polyline corners, item IDs, reciprocal contacts, engine connected sets and plane-net flags. A count above the finite observation limit records its census before failing; a bounded unexpected census is a visible mismatch. Full trace coordinates/classes are retained. Only actual integer points whose declared transform exactly agrees with DSN coordinates can qualify. Rational points remain observable but unqualified. Trace splitting is permitted only when exact rational arithmetic proves collinear, same-layer/net/width segments cover the entire original segment exactly, with no gap, overlap, overhang or excursion. A repeated or bent path cannot pass via endpoint equality.

Expected capability requires true-state reciprocal anchor↔area and area↔trace contacts, independently traversed complete original-terminal connectivity, correct false-hull disconnection, and `containsPlane=false`. Both the original Default 500 µm width and the actual area↔foreign-trace clearance matrix value of 250 µm are checked. Foreign intrusion must pass the actual default-tree trace-shape check with obstacle=false and fail it with obstacle=true, with the concave area in the failing trace's clearance overlap set. This is an **engine search-tree/trace-shape observation**, not a native DRC error or an electrical claim. Parser warnings and every failed case are retained; a hypothesis mismatch can finish as an observation with `expected_observations_match=false`.

Scope is the two Y-symmetric polygons and tested front0/back90 poses on the six owned Default-only scenes. The original PIC board instead places the convex pad on VCC/POWER and the concave pad on a Default net. That future transport requires distinct class/matrix and native acceptance work, including the change from a pad's smd_smd class to an area's class. No arbitrary reflection, original-board feasibility, unused POWER, mixed-class clearance, SES survival, routing improvement or generalized custom-pad support follows here.

The controller uses one foreground experiment lock, a fresh direct `.runs` directory, exact committed helper/core/native-basis and tool bytes, 60 shared wall/full SELF+waited-CHILDREN CPU seconds, 10 MiB output, 256 MiB Java heap, 1 GiB polled worker-group RSS, bounded logs and OS network denial for compiler/import. It isolates HOME/TMP, disables annotation processing, preserves raw process/output evidence before parsing, checks snapshots after stages and publication, and invalidates positive metadata on cancellation/staleness/expiry. Stored cost precedes final checks; final caps include them. Polling can overshoot. Finite local sampling is neither atomic protection from arbitrary concurrent writers nor authenticity/signatures.
