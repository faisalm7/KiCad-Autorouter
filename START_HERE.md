2. Open the prepared inspection project in its PCB Editor and click the small green trace icon beside `>_`. The assistant opens in a separate window. This demo launcher is bound to the saved source under `gui-session114/source`; the inspection project is a separate copy. Confirm the displayed source/output paths, keep original source editors closed, and use fresh outputs. Existing jobs, source-fault copies and the edited export are retained test evidence.
3. Use **Placement** to inspect the saved project and its findings. Choose eligible components and an allowed rectangle, load/save settings, inspect alternatives and edit coordinates. Fixed and protected components remain fixed. Rebuilding affected unlocked copper requires explicit settings and review of the exact plan; preserve-all is the default. Current support is fixed-angle front translation with conservative geometry/annotation checks. The new **Keep selected parts together** setting makes one rigid group and requires affected-net rebuilding. Automatic search may return no changed alternative; **Review current group arrangement** explicitly starts an original-layout manual review instead. One-member edits translate that group. These088graphical controls have now been exercised through separate-project delivery. Multiple groups, preserve-all grouping, orientation/side changes and advanced keepouts remain unsupported.
4. Explicitly review the draft, validate it with KiCad, then continue to Routing. Routing can also be used directly. Confirm scope, protected copper, supported layers, preferences and time budget. **Finish gaps** preserves all existing routes; whole routing preserves locked copper. Selected-net routing is narrow and experimental. Preview explains refused inputs. Start the job or Cancel while it runs.
5. Create review, inspect both copper layers and every finding in **Microsoft Edge**, then choose Accept intent or Reject intent. Acceptance records intent; it is not PCB engineering approval. Fresh export validates again and writes a separate project. **Open checked export** checks the exact current evidence before opening. Editor sidecar writes may stale the packet even when PCB bytes stay unchanged; the next opening must refuse it.

Original projects are not overwritten. Native checks, rules, connectivity and protected-copper checks remain mandatory. A changed-warning offer, when eligible, requires a new explicit acknowledgement of that exact candidate/report within the original deadline; it cannot waive blocking findings. The genuine changed-warning GUI branch and exact queued-open interval remain unexercised. Software-test acceptance is not human PCB approval.
