# Start with your saved KiCad project

Use your existing installation and launcher. The ordinary controls have completed placement, protected routing and checked delivery on the owned example, which includes a reusable preset. A later installed check also delivered a board with a round cutout. [Owned walkthrough](examples/owned-placement-routing/README.md) · [Checked cutout delivery](evidence/product-round-cutout-checked-delivery-002.json) · [Current state](STATUS.md).

For a first installation on the tested Mac, use the existing pinned tools and
follow [first setup](docs/install-existing.md#first-setup-with-existing-mac-tools).
An existing installation can keep its launcher.

1. **Open Copperpath.** Double-click **Copperpath.app** in your launcher folder. If the folder has **Open Saved Project.command**, that also opens the workspace and shows setup errors in Terminal. The PCB toolbar is another way to open Copperpath. Keep the installation and its dependencies in place. [Local setup and launch](docs/install-existing.md).
2. **Choose your saved project.** Use **Choose project…** and select the `.kicad_pro` beside its matching PCB, schematic and rules. To try the bundled project, choose **Open example** on the empty workspace. Copperpath inspects and opens the board in the same window. If your project is open in KiCad, save and close the editors, use **File → Close Project** in KiCad manager, and then choose **Refresh inspection** in Copperpath.
3. **Choose the task.** Read the source findings and support limits. Choose **Route saved board** to keep the saved placements. To place parts, select the movable components on the board and draw the allowed area. Review copper protection before requesting alternatives. Rebuilding affected copper requires explicit review of the affected-net plan. [Workspace controls](docs/saved-project-workspace.md)
4. **Review a proposal before work.** Placement alternatives and coordinate edits are geometry drafts. Invalid edits refuse. The search may also return no changed alternative. When **Approve placement and validate** is available, review the moves and copper plan and choose it once. Earlier builds use the draft acknowledgement followed by **Validate placement**. Select **Board** if an older build keeps that action disabled in Findings. Direct routing uses the same preview and validation flow.
5. **Preview, route and review.** Preview checks the requested scope before routing. **Finish gaps** also uses KiCad to identify the open connections. **Start routing** works on a separate copy. Choose **Review result** to see copper changes and findings beside the controls. After checking the findings, choose **Accept result** or **Reject**. This records your software choice. Electrical and manufacturing approval remain separate. **Detailed report** is available for full KiCad plots.
6. **Export and continue deliberately.** **Fresh export** runs new original-rule Native checks for a separate project. **Open checked export** verifies current proof before opening it. Opening or editing that project can change sidecars and invalidate the old proof even when PCB bytes stay the same. For further work, save a separate complete working project, select it as your new source and inspect/validate it afresh; do not restore sidecars or edit receipts to revive old acceptance.

**Cancel** requests cancellation of owned work, revokes positive state and retains evidence. Wait for cleanup before closing the assistant or starting another action. Changing the source, settings, target-region policy or reviewed pose also revokes earlier validation and handoff authority. A stale or cancelled result needs a fresh explicit workflow.

Keep an untouched complete copy before opening an older project in newer KiCad. Closing the editor can update project settings even without a board edit. If the original settings must be preserved byte for byte, select the untouched saved copy in the assistant. [Observed EEPROM workflow](docs/eeprom-finish-gaps-gui127.md).

Routing-scope acceptance, whole-project DRC cleanliness and electrical/physical suitability are different checks. Warnings and ignored checks remain visible. The checked move and Undo apply to the supplied owned example on isolated KiCad 10.0.8. General live editing, Windows Native, independent installation and human PCB review still need qualification.
