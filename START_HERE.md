# Start with your saved KiCad project

Use your existing installation and launcher. The ordinary controls have completed placement, protected routing and fresh delivery on the owned example, which includes a reusable preset. The live copilot and safety checks have their own results. [Ordinary workflow](evidence/product103-GUI126-ordinary-delivery-001.json) · [Owned walkthrough](examples/owned-placement-routing/README.md) · [Live copilot](evidence/copilot102-owned-live-delivery-001.json) · [Safety controls](evidence/product101-GUI124-core-001.json).

If you need installation, use [prerequisites and advanced setup](docs/install-existing.md). There is no turnkey download or standalone installer; do not reinstall merely to resume.

1. **Open Copperpath.** If your launcher includes **Open Saved Project.command**, double-click it to start directly. Earlier launchers use **Launch Autorouter.command**, then the green toolbar icon in PCB Editor. Keep the bound installation and dependencies in place. [New launcher and test coverage](docs/saved-project-and-review104.md).
2. **Choose your saved project.** Use **Choose project…** and select the `.kicad_pro` beside its matching PCB, schematic and rules. Use a separate output folder. If that source is open in KiCad, save and close its PCB and schematic editors, then use **File → Close Project** in the manager. Confirm that the selected saved files are correct and the project is closed.
3. **Inspect and choose the task.** Read the source findings and support limits. Route directly, or choose **Place components…** for a supported selected-component task. Select movable parts, leave fixed parts unselected, enter the allowed rectangle and review existing-copper protection. Rebuilding affected copper requires explicit permission and review of the complete affected-net plan. [Detailed workflow](docs/quickstart.md).
4. **Review a proposal before work.** Placement alternatives and coordinate edits are geometry drafts. Invalid edits refuse. The search may also return no changed alternative. When **Approve placement and validate** is available, review the moves and copper plan and choose it once. Earlier builds use the draft acknowledgement followed by **Validate placement**. Select **Board** if an older build keeps that action disabled in Findings. Direct routing uses the same preview and validation flow.
5. **Preview, route and review.** Preview checks static support. Route performs the bounded operation on a separate copy. Read every finding and inspect the review layers; Microsoft Edge is the browser used in qualification. **Accept intent** records a choice; **Reject intent** leaves no accepted export. Neither is electrical or manufacturing approval.
6. **Export and continue deliberately.** **Fresh export** runs new original-rule Native checks for a separate project. **Open checked export** verifies current proof before opening it. Opening or editing that project can change sidecars and invalidate the old proof even when PCB bytes stay the same. For further work, save a separate complete working project, select it as your new source and inspect/validate it afresh; do not restore sidecars or edit receipts to revive old acceptance.

**Cancel** requests cancellation of owned work, revokes positive state and retains evidence. Wait for cleanup before closing the assistant or starting another action. Changing the source, settings, target-region policy or reviewed pose also revokes earlier validation and handoff authority. A stale or cancelled result needs a fresh explicit workflow.

Keep an untouched complete copy before opening an older project in newer KiCad. Closing the editor can update project settings even without a board edit. If the original settings must be preserved byte for byte, select the untouched saved copy in the assistant. [Observed EEPROM workflow](docs/eeprom-finish-gaps-gui127.md).

Routing-scope acceptance, whole-project DRC cleanliness and electrical/physical suitability are different checks. Warnings and ignored checks remain visible. The checked move and Undo apply to the supplied owned example on isolated KiCad 10.0.8. General live editing, Windows Native, independent installation and human PCB review still need qualification.
