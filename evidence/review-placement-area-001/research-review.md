# Independent placement-area premise and review boundaries

Read-only inspection confirmed the pinned 10.0.0 source distinction at commit `0feeca2a807f428ad2b3fa7c1e39625cb769f02c`: `specctra_export.cpp` board rule-area loop emits a generic keepout when neither tracks nor vias is prohibited; `drc_engine.cpp` only creates the implicit area prohibition when at least one of the five flags is set. `ZONE::HasKeepoutParametersSet` is the OR of those five flags. This supports the narrow semantic premise; custom rules and placement intent remain separate, and the original board must retain them.

The retained multichannel source and raw native DSN were independently parsed using exact Decimal coordinates without truncation. All relevant coordinates were integer micrometres; four unique enabled sheet placement areas, each explicitly allowing all five categories, correspond bijectively to exactly eight structure-level generic keepouts. Source SHA `44b7c119a0d05c98e9f294659879184038a5f6c30073c04d9536990429ca413e`; raw DSN SHA `bc56d6dc224951a0d5b0faf7dd12fe71693d9fb06e3167f191fa43ad9f6e60c4`. Original bytes remained unchanged. This does not establish that removing the false interchange obstacles completes the board or explains every open.

Critical pre-promotion boundaries:

1. Admit only a full exact native/source zone census from the same loaded input used for export, including all five typed flags, original placement type/enabled state, layer set, contour identities and footprint-zone count. Never infer eligibility only from a DSN shape or an all-allowed default after missing fields. Relocation must bind the actual loaded input path, board, project, complete tree and raw DSN together.
2. Bijection must account for multiplicity and provenance. Identical or overlapping genuine obstacles must not be consumed as apparent placement areas. Initial simple outer rectangle/no board cutouts and no footprint Edge.Cuts or footprint rule areas is an acceptable explicit limitation. Keep image-level copperless-pad keepouts and every unmatched typed structure obstacle unchanged.
3. Exact source→native→DSN coordinate conversion must not round/truncate a near match into a match. Reject unsupported subunit/precision geometry unless the exact pinned serialization is qualified. Require the expected closed polygon, layer, zero aperture, type, no windows and no extra rule/shape fields; duplicate declarations are not harmless.
4. Native negative controls must identify the relevant area and crossing track/via, not merely observe an unrelated error. The mixed scene must retain genuine wire/via/generic prohibitions while removing only the allowed-area interchange object. Keep original rules, source zones and geometry unchanged; final native validation uses them.
5. This is a common B1 representation correction. Version policy explicitly; never reinterpret board-floors-v1 history. Preserve raw→floor-guided→placement-corrected→adapted intermediates and reject missing/downgraded chains in readback. Pure mocks cannot qualify same-load native API behavior or electrical/physical suitability.
