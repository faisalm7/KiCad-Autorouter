# Placement-area diagnostic transform — frozen for review

A pure adapter-attribution draft, not production policy or native acceptance. No KiCad/solver job was executed. The callable transform(original_files, native_input_files, board_name, observation, raw_dsn, guided_dsn) accepts complete immutable byte snapshots and returns transformed bytes plus a deterministic receipt. A trusted caller must separately authenticate the actual same-load observation process/tool/code, validate upstream board-floor guidance, then apply this transform followed by existing both adapter, and finally perform unchanged native validation. The function alone cannot authenticate a maliciously rewritten history or call a board routed.

The native input must equal the original parsed board or exactly the existing task_from_source(original), not merely share a stripped tree. Every non-board project file is byte-identical; custom-rule files reject even if empty. Expected observation schema agrees with frozen native_areas.py in .runs/placement-area-native-draft-001 (worker SHA1c20e255b69eea8bb9ddd0ae864bbed5ac7797719866de4fc51e3bc326913771). All source/native zone identities, layers, integer coordinates, topology and explicit rule flags bind. Original source may contain ordinary copper zones and saved fills; those are never removal candidates.

Scope: two canonical outer copper layers, exactly one four-line axis-aligned source outer rectangle and an identical raw/guided DSN boundary, no cutouts or footprint zones/edges/image keepouts. Source/native zones require bounded simple hole-free, arc-free outlines. Enabled SHEETNAME placement with all five explicitly allowed source flags and all five false native disallow flags is removable. Genuine prohibited areas and disabled placement remain. Unknown source attributes/DSN obstacle geometry/types/units or source enum values fail closed. Native fields have strict Boolean/integer types.

The complete DSN structure keepout population must map bijectively to the full source rule-area population using pinned10.0.0 type/layer/point-order/closure semantics. Missing, duplicate, extra or near-match objects reject. Removal candidates cannot bbox-overlap another rule area or exported keepout on a common layer. This conservative gate rejects the native fixture agent's overlapping mixed scene; its expected role is a negative transform control. Independent pure disjoint mixed scenes prove genuine wire/via/generic entries survive unchanged. Every nonremoved AST entry, including nets/planes/placements, remains exactly identical. Formatting of the overall DSN is canonicalized, so byte identity is promised for retained input streams and AST identity for untouched output entries.
