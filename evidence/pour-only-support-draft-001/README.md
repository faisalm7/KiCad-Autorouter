# Root pour-only source and DSN draft

No production admission. ROOT promotes pour_rule_area.py only after review and integrates it with mandatory saved-fill BooleanIntersection checks, source/original-rule invariants, native DRC/parity, provenance and final-candidate read-back. This pure module does not import KiCad, load/refill boards, bypass text guards or assert a native export.

`qualify(board_tree)` returns source records only for root net0 areas whose five explicit unique flags allow tracks/vias/pads/footprints and prohibit copperpour. F.Cu/B.Cu selectors must be explicit, unique and declared. UUID is unique across board objects. One simple XY contour, no arcs/holes/collinear/repeated points, bounded128 vertices. Placement is absent or disabled; short disabled form is supported via an internal parser-only metadata copy. Unknown restricted-zone/nested metadata, enabled placement, other/combined restrictions and restricted footprint areas fail closed. Existing all-allowed areas are untouched, and ordinary copper zones are outside this qualifier.

`correct(source_board_bytes, raw_dsn_bytes)` returns corrected bytes plus hash-bound pure attribution. Use the raw native export before graphic/plane adapter changes. It deletes only one empty-name generic keepout per area/layer matching exact source ordered vertices, zero width, declared F/B.Cu and um units. Cyclic/reversed ring equivalence detects collisions only; it does not justify deletion. Duplicate/equivalent source or export polygons, signal aliases, wrong keepout kinds/names and missing entries reject. Known disjoint non-target polygon keepouts and every unrelated AST atom survive exactly. Unknown/non-polygon keepout geometry and non-root/image keepout provenance are conservatively unsupported; this is a deliberate narrow limitation.

Inputs are immutable bytes/ASTs and output is a deep-copy deletion plus shared-parser/serializer round-trip. A source record is not a native observation; a DSN attribution record is not routing or pour validation. No target areas returns byte-identical DSN without interpreting it; the caller retains its ordinary parser/format checks. Native context/provenance and final saved fills remain independently mandatory. Actual NUS source has eligible F.Cu UUID1abd2188-f015-4692-bf4a-117c7482b9fc; its B.SilkS knockout text remains a separate guard. No models, rules, zones, locks or copper intent are changed.

Pure tests: `.venv/bin/python -B .runs/pour-only-support-draft-001/test_pour_rule_area.py`. Sixteen tests passed under explicit supervisor3.11.9 and stdlib3.9.6 (no KiCad/JVM/Git/network execution). They cover authored synthetic DSNs, actual byte-pinned NUS source-form parsing, nested unknowns, other restrictions, geometry/UUID/layer ambiguities, duplicate attribution and full AST preservation. They establish no native outcome. Tests include one existing-data-dependent source check; they are not clean-install proof. Native positive/invalid controls are owned and recorded separately by ROOT.
