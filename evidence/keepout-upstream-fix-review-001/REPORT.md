[Official macOS download](https://www.kicad.org/download/macos/), [release announcement](https://www.kicad.org/blog/2026/10/KiCad-10.0.7-Release/), [official tags](https://gitlab.com/kicad/code/kicad/-/tags).

Two exact source changes address the mechanisms diagnosed in our 10.0.0 controls:

- `ZONE::GetEffectiveShape` now returns a rule area's outline before consulting the copper-fill map. The original function used only the fill map. This supplies actual rule geometry to the existing DRC spatial-index insertion path. [10.0.7 zone.cpp, lines1717–1729](https://github.com/KiCad/kicad-source-mirror/blob/69cafb907ebc09e7722a2a464b1d466fc2e3608d/pcbnew/zone.cpp#L1717).
- The disallow provider's unconditional skip of implicit constraints is replaced by a skip only for tracks/arcs, which its separate intersection path already handles. Other item types can now emit an implicit-rule violation. Its area collection also independently gathers track and copper-pour prohibitions instead of using an `else if`. These are direct code changes relevant to the missing track and via findings. [10.0.7 disallow provider, lines263–324](https://github.com/KiCad/kicad-source-mirror/blob/69cafb907ebc09e7722a2a464b1d466fc2e3608d/pcbnew/drc/drc_test_provider_disallow.cpp#L263).

The placement-only DSN fallback is **unchanged**. The entire board-rule-area keepout export block is byte-identical between the two pinned commits (10.0.0 lines1307–1408; 10.0.7 lines1311–1412). It still emits generic `T_keepout` when both track and via prohibitions are false. Its hash/equality check is retained in targeted-comparison.json; it does not rely on release-note wording. [10.0.7 exporter](https://github.com/KiCad/kicad-source-mirror/blob/69cafb907ebc09e7722a2a464b1d466fc2e3608d/pcbnew/specctra_import_export/specctra_export.cpp#L1312).
