## Narrow proposed correction

Begin with a complete immutable original project and same-load native observation of every board zone and every footprint-zone count. Reject custom rules, footprint rule areas, unknown/duplicate flags, missing/extra observation identities, nonboolean flags, unsupported layers, malformed/degenerate/selfintersecting contours, arcs/holes, disabled placement eligibility, or unrecognized placement type. Initially eligible only board-local enabled SHEETNAME placement areas with all five source fields explicitly allowed and every native disallow boolean false. Names, coordinates and UUIDs are never hardcoded.

Bind sourceboard/project/full input tree, native version/tool/helper hashes and DSN hash. Derive each eligible area’s exact generic keepout polygon per native copper layer. Require a bijection: exactly one matching DSN object per zone-layer, no sharedmatch, missing/duplicate/extra generated representation, unknown nestedshape/window/rule, or ambiguous collision with a genuine rule-area/cutout/image obstacle. Conservative geometric overlap/containment ambiguity is unsupported; bbox rejection is acceptable for this narrow scope, even if it declines otherwise harmless cases. Preserve all unmatched DSN entries identically as ASTs, including wire_keepout/via_keepout/genuine generic keepouts and board-boundary cutouts. Original zones, rules, nets, placements and geometry remain untouched.

Order: native rawDSN → board-floors-v1 guidedDSN → explicit placement correction → existing both adapter. Retain every intermediate byte stream and reconstruct each deterministic transformation during readback. This is an adapter input-policy change, not C novelty. Keep the already frozen two-arm harness unpromoted until root chooses a prospective three-policy ablation.
