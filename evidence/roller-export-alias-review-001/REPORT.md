The original Roller source has no `%R`/`%V` surface occurrence. Its `${...}` model paths are unrelated to this text guard and remain unresolved physical/dependency rights evidence, not a reason to erase models or relax constraints. The counterexample is synthetic; no original board changed.

## Scope and remaining proof obligations

Pinned exporter source checks duplicate references across every footprint before exporting (`specctra_export.cpp1076–1097`). `makeIMAGE` consumes pads, courtyard and PCB_SHAPE objects; it does not export footprint PCB_TEXT. Reference determines placement identity and electrical pin component identifiers (`1436–1486`). Accordingly, two namespace-equivalent DSNs alone cannot prove source copper equality or expose aliased rendered copper text. The protocol correctly requires an independent during-alias copper/terminal/obstacle observation as well as exact restored native state and source hash. These callbacks must be real geometry observations, not the test fixture's reference-only mock.

Native importer resolves every session place by reference and moves/orients/flips the matching footprint (`specctra_import.cpp416–454`). It deletes/rebuilds unlocked routing and retains locked routes (`371–398`). The proposed approach must therefore retain every source footprint, validate complete fixed placement first, strip only the matched padless alias placements, then import into the pristine original. All eleven original tracks must be protected and survive exact route transplantation/reconciliation. Full source/candidate immutable checks, fresh refill and complete original-rule native/parity acceptance remain required. Importing raw aliased SES into the original or translating aliases back into duplicated original references is unsupported.

Source inspection found the partial setter/cancellation restoration logic consistent with its stated contract: aliases are recorded before setter invocation, restoration runs in reverse in `finally`, subsequent restoration attempts continue after a setter failure, and restoration/observer failures chain the original cause. `require_plan` recomputes the complete source binding; no source/candidate file is written by the transformer. The native census proves UUID/reference/pad counts only; it does not itself establish that an in-memory board's copper/full geometry equals the captured source. The protocol must supply that separate before/during/after native proof and bind source/project/context/DSN and all process costs. Restoration before a saved native emission is essential.

The SES helper explicitly is not a complete session or routing validator. It must not be used alone as acceptance: its placement comparison reuses the shared strict helper, while caller-owned grammar/route/library/net/protected survival and final native validation remain mandatory. Native image/terminal mapping, source equality, active class settings and exact transport have not been qualified by this review. The physically retained original5mil definition must remain present; inactiveDefault proof cannot cover an actually active5mil class.
