# Engineered placement-pruning controls

Original six-terminal smoke geometry and this control generator are project-owned GPL-3.0 work. The derived sources add one all-allowed placement area; the necessary-copper source additionally shortens the B.Cu GND zone at x=24mm. Every original smoke file remains unchanged. These are development-exposed engineered controls, not independent board families or quality-comparison evidence.

It remains separately CC BY-SA 4.0; original license/notice copies remain in _licenses. Its existing five explicit ignored checks are inherited unchanged and fully reported. No new severity/exclusion is introduced.
