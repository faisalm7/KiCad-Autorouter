# PIC mixed-class transport probe — independent source review

Disposition: corrected source is suitable for the bounded ROOT-only observation. Native/JVM/compiler execution has not occurred in this review; native import, API return behavior and mixed-clearance equivalence remain unqualified.

Three material gaps were identified and corrected before promotion:

1. Import JSON could claim post-load router/optimizer enabled, deferred initialization not awaited, SES executed, or a Boolean schema and still complete. The corrected checker requires exact integer schema, no routing/SES, awaited post-load work, and router/optimizer false both before and after import.
2. Only assigned pins were checked. Removing, adding or moving unassigned imported pins still completed. The corrected expectation derives every placed pin from the exact raw DSN image/placement AST, admits only the original orthogonal front rotations and back180, and compares the complete imported identity/net/position set and count. It separately cross-checks all 236 assigned pins against native positions. The original native census is 247 pads; its DSN has 240 pins (236 assigned plus P3 @1/@2 and J1 SH/SH@1). Seven other netless native pads are not DSN pins. These distinct populations must not be described as 247 imported pins.
3. The original runtime witness pinned Python and pcbnew.py but omitted the native `_pcbnew.so` implementing the queried APIs. The corrected protocol includes its existing exact toolchain lock entry, sampled by the same bounded runtime helper before/after. A small-file regression verifies that a changed fake extension changes the witness; no installed binary was altered.

A small additional truth-order correction moves native/import execution flags immediately after the returned owned PID, before capture may fail. Failed capture still rejects; a real executed worker is no longer recorded as unexecuted.

Evidence: the original ten copied pure methods passed, but the independent ten-case probe exposed nine unintended completions. With corrected source, the same probe script retains the positive and rejects all nine negatives; all fourteen copied pure methods pass in 0.624 s. Synthetic builder fields were updated with the new complete census contract, including correct DSN negative-Y positions; these are controlled JSON observations, not native or importer evidence. Both original and corrected sources, outputs and the original failure evidence remain local. The first standalone reviewer acquisition-check import missed the legacy helper module path; its reviewer-only error and successful corrected invocation are retained separately.

The source review confirms one complete immutable 15-file/1,366,598-byte original project, exact acquisition pins, and 32 matched cached source/API basis files. The reverse AST proof restricts DSN edits to two custom anchor shapes plus two native-world same-net protected area bodies; original wires, vias, plane, class rules and placements remain. Native same-board pre/post-initialization getters and raw text report are retained; optionals stay unsupported unless literally None or bounded int. The text DRC report is not routing acceptance. Complete before/after-export identities and exact matrix readbacks remain observational.

The actual manager lifecycle uses fresh jobs, assigned merged settings before loading, the exact input bytes without a counterpart filename, and awaited post-load work. It constructs no scheduler, routing pipeline or SES writer. Both settings cases share the existing foreground lock, 180 s observed wall/full CPU budget, 64 MiB output, 2,000 files/4,000 entries, 256 MiB Java heap, isolated environment and network denial. Existing stage capture precedes parsing; runtime sampling is bracketed by frozen output checks, with strict canonical publication and cancellation invalidation. CPU is an acceptance cap, not OS preemption; finite local samples are not atomic authentication.

No claim is made that original reference routes are rerouted, normalized imported traces are union-equivalent, plane shortcuts are qualified, local/pairwise rules are transported equivalently, or production custom-pad support is available. Those remain future gates rather than blockers to this observation-only experiment.
