# KiCad-Autorouter

A local, open-source KiCad design assistant built around Freerouting. Ordinary controls support routing and constrained selected-component placement without an AI account. Deterministic tools enforce supported constraints, preserve protected content and validate separate candidates. An optional copilot can propose settings; it cannot run, approve or accept a board. [Product strategy](docs/product-strategy.md).

**Experimental software, not a qualified release.** The current tested finite reference is **runtime101 / GUI124**, on one Mac with pinned KiCad10.0.7 and existing dependencies. One owned target-region task completed automatic placement, protected routing, review, fresh export and checked PCB opening with **0 opens, 0 blocking findings and 1 unchanged warning**, plus2original ignored checks. Complete source files and protected copper remained unchanged. Cancellation and stale-source/settings/export refusal were observed. This is not whole-project DRC cleanliness, electrical approval or broad placement usefulness. The retained **094 / GUI118 licensed-task reference** has its own [delivery](evidence/runtime094-licensed-placement-delivery-001.json) and [GUI evidence](evidence/runtime094-GUI118-core-001.json). Historical failures remain recorded. No general routing superiority or measured human cleanup gain is established.

Use your installed launcher and your own complete saved project. Inspect the exact source, choose supported settings, preview, run, review every finding, and explicitly accept or reject. Fresh export creates a separately validated project; it never applies changes to an open source board. Cancel requests cleanup and revokes results. Source, settings or editor-sidecar changes require fresh checks.

Placement remains limited to its explicit geometry and copper policies. Unselected/fixed components stay fixed; orientation and side changes are unsupported. The opt-in target-region initializer covers two independent selected parts in its specific Native source-baseline scope, not general repair of an invalid or unplaced board. Unsupported requests refuse. The current101installation/full integration/Native/GUI evidence covers that narrow saved-project workflow. Previous095export,100saved-Default and other failures remain recorded; source-only changes do not inherit graphical qualification.

Same-Mac/account testing is not standalone or independent installation. Windows Native workflows, live apply/undo, full current/off-Mac recovery and human/physical/electrical review remain open. Normal routing needs no model endpoint, network, Git or research archive. A separate reproduced metadata compatibility fix is source work, not successful live integration. End-to-end copilot usefulness remains unqualified. No private-board upload is authorized or AI account required.
