# KiCad-Autorouter

An experimental, open-source KiCad autorouter that runs locally without an AI account. It preserves original constraints and protected copper, validates separate candidates with native KiCad, and provides saved routing settings, preview, progress, cancellation, review and explicit accept/reject intent.

[Start here](START_HERE.md) · [Install locally](docs/runtime-directory.md) · [KiCad workflow](docs/gui-workflow.md) · [Preferences](docs/routing-preferences.md) · [CLI demo](docs/quickstart.md) · [Structured interface](docs/structured-interface.md)
