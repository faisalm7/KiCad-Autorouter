# Copperpath — KiCad-Autorouter

A local, open-source KiCad design assistant built around Freerouting. Ordinary controls support routing and constrained selected-component placement without an AI account. Deterministic tools enforce supported constraints, preserve protected content and validate separate candidates. An optional copilot can propose settings; it cannot run, approve or accept a board. [Product strategy](docs/product-strategy.md).
