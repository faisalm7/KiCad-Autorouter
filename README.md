# KiCad-Autorouter

An experimental open-source KiCad autorouter that runs locally without an AI account. It preserves original design constraints and protected copper, validates separate candidates with native KiCad, and provides saved settings, preview, progress, cancellation, review and explicit accept/reject intent.
