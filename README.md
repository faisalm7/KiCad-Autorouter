# KiCad-Autorouter

A local open-source KiCad design assistant under development, built around Freerouting. Routing works without an AI account, preserves original constraints and protected copper, and validates separate candidates. Constrained automatic placement is a core next feature; an optional copilot proposes settings through the same guarded tools. See the [architecture and reuse decision](docs/product-strategy.md).

**No version is a qualified release.** [Runtime076](evidence/runtime076-placement-product-milestone-001.json) now demonstrates one installed selected-placement → protected-routing → reviewed separate-project delivery workflow. The KiCad-launched controls support saved presets, alternatives and coordinate edits, actual Native validation, Edge previews, explicit accept/reject, cancellation and stale-result refusal. Placement currently supports only narrow front/unrotated circular-PTH translation tasks; ordinary SMD/library footprints, grouping and broader constraints remain open. [Placement workflow and limits](docs/placement-review.md).

The prior074/075 routing milestones and all failures remain versioned evidence, not repeated or relabelled results. Genuine changed-warning GUI interaction, exact queued-opening timing and a live model endpoint remain untested. Ordinary controls work without AI.
