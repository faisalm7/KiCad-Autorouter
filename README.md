# KiCad-Autorouter

A local, open-source KiCad design assistant built around Freerouting. Ordinary controls support routing and constrained selected-component placement without an AI account. Deterministic tools enforce supported constraints, preserve protected content and validate separate candidates. An optional copilot can propose settings; it cannot run, approve or accept a board. [Product strategy](docs/product-strategy.md).

**Experimental software, not a qualified release.** The current tested finite reference is **runtime096 / GUI120**, on one Mac with pinned KiCad 10.0.7 and existing dependencies. One owned target-region task completed automatic placement, protected routing, review, fresh export and checked PCB opening with **0 opens, 0 blocking findings and 1 unchanged warning**, plus 2 original ignored checks. Source files and protected copper remained unchanged. This is not whole-project DRC cleanliness, electrical approval or evidence of broad placement usefulness. [Native delivery](evidence/runtime096-region-delivery-001.json) · [Actual GUI120 workflow and limits](evidence/runtime096-GUI120-core-001.json).

The retained **094 / GUI118 licensed-task reference** has its own [delivery](evidence/runtime094-licensed-placement-delivery-001.json) and [GUI evidence](evidence/runtime094-GUI118-core-001.json). Historical failures remain recorded. No general routing superiority or measured human cleanup gain is established.

Use your installed launcher and your own complete saved project. Inspect the exact source, choose supported settings, preview, run, review every finding, and explicitly accept or reject. Fresh export creates a separately validated project; it never applies changes to an open source board. Cancel requests cleanup and revokes results. Source, settings or editor-sidecar changes require fresh checks.

Placement remains limited to its explicit geometry and copper policies. Unselected/fixed components stay fixed; orientation and side changes are unsupported. The opt-in target-region initializer covers two independent selected parts in its specific Native source-baseline scope, not general repair of an invalid or unplaced board. Unsupported requests refuse. The corrected098 source combines visual controls, shared intent and portable-install changes; its new-build qualification remains open. Runtime096 evidence does not qualify those changed bytes.

Same-Mac/account testing is not standalone or independent installation. Windows Native workflows, live apply/undo, full current/off-Mac recovery and human/physical/electrical review remain open. Normal routing needs no model endpoint, network, Git or research archive. The [completed synthetic model screen](evidence/copilot-screen097-completed-001.json) qualifies neither model and exposes a tool-contract defect; its shared correction is integrated in source, awaiting final-build qualification. Actual end-to-end copilot usefulness remains untested. No private-board upload is authorized or AI account required.

Original code and owned fixtures are GPL-3.0-or-later. Reused MIT placement modules retain their notice; other material keeps its separate [rights and provenance](docs/data-provenance.md). Freerouting remains the primary routing engine. No formal package or release is claimed.
