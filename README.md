# KiCad-Autorouter

An experimental open-source local KiCad autorouter. It runs without an AI account, preserves original design constraints and protected copper, validates separate candidates with native KiCad, and offers saved routing settings, preview, cancellation, review, acceptance/rejection intent and fresh separate-project export.

The tested platform is this Mac's arm64 environment with pinned KiCad10.0.0, Freerouting2.5.0, Java25.0.2 and Python3.11. Ordinary routing needs no Git, historical archive, model, subscription or internet. This is a fixed-path directory using existing applications, not a standalone installer. Windows/current stable-version qualification, live-editor transaction/undo and unsaved-buffer inspection remain open. [Installation scope](docs/install-test.md), [supported matrix and ranked issues](docs/experimental-rc.md).

Routing effectiveness remains an unmet project goal. Exposed development comparisons contain narrower length gains, ties, failures and budget losses beyond measured corrected/tuned configurations. [Installed Sonde007](evidence/installed-workflow-sonde007-native-001.json) retains stock failure and valid B1/B2/C results; C is shorter but slower, with about99.36%of its length difference on GND. These results do not establish added completion, broad signal-routing or cleanup improvement, electrical suitability, independent families or untouched confirmation. Corrected-standard is the default; single pruning is optional. [Evidence and claims](evidence/claims.json), [original requirements](REQUIREMENTS.md).

Whole/partial/selected-net scopes have different support restrictions. Rules, severities, exclusions, nets/terminals, footprints/pads, stackup, edges/cutouts, zones/keepouts and protected copper are never weakened to pass. Unsupported current, return-path, impedance, timing and other advanced requirements cannot be inferred from net names or DRC. Runtime014 admits narrow ordinary flat-class Route contexts only after independent task/final observations. Hierarchies, unknown inheritance and class-bearing Improve/Recover remain unsupported; see STATUS.md. The archived006 class-intent false acceptance remains disclosed. Native routing acceptance, whole-project cleanliness and human/electrical/manufacturing approval are separate.

Original code and owned fixtures are GPL-3.0-or-later. Downloaded hardware and engines have separate [rights and provenance](docs/data-provenance.md); raw third-party boards/models are not redistributed. No telemetry, chatbot, runtime model, novelty training or formal release/package publication is included.
